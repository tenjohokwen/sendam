  <action>
Create `src/frontend/src/components/common/ServerPagination.vue` using `<script setup>` (plain JS, no TypeScript).

**Props:**
- `totalElements` — Number, required. Total record count from `Page.totalElements`.
- `totalPages` — Number, required. Total page count from `Page.totalPages`.
- `pageSize` — Number, default 20. Records per page (used for summary calculation).
- `modelValue` — Number, default 1. Current page in 1-based QPagination numbering.

**Emits:**
- `update:modelValue` — emits the new 1-based page number (for v-model compatibility)
- `page-change` — emits the new 0-based page number (for Spring Data `?page=` query param)

**Template:**
Wrap everything in a `v-if="totalPages > 1"` `<div>` with class `row justify-center q-mt-md`.

Inside:
1. A `<q-pagination>` with:
   - `v-model="currentPage"`
   - `:max="totalPages"`
   - `:max-pages="7"`
   - `boundary-numbers`
   - `direction-links`
   - `@update:model-value="onPageChange"`

2. A summary `<div>` with classes `text-caption text-grey-7 q-ml-md self-center` displaying:
   `{{ t('pagination.summary', { from: fromItem, to: toItem, total: totalElements }) }}`

**Script:**
```
import { ref, computed, watch } from 'vue'
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

// props and emits as above

const currentPage = ref(props.modelValue)

// Keep currentPage in sync when parent resets modelValue (e.g., after filter change)
watch(() => props.modelValue, val => { currentPage.value = val })

// Compute display range for summary
const fromItem = computed(() => (currentPage.value - 1) * props.pageSize + 1)
const toItem = computed(() => Math.min(currentPage.value * props.pageSize, props.totalElements))

function onPageChange(page) {
  emit('update:modelValue', page)
  emit('page-change', page - 1) // Convert 1-based UI to 0-based Spring Data
}
```

Do NOT add ARIA attributes beyond what QPagination provides internally — QPagination is already WCAG-compliant. Do NOT add a custom loading state — parent pages handle loading via QInnerLoading.
