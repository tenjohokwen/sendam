```java
public void createAlert(SegmentDeviationAlertData data) {
    SegmentDeviationAlert alert = SegmentDeviationAlert.builder()
        .sendRequestIdFk(data.sendRequestPk())
        .sendRequestRef(data.sendRequestRef())
        .clientId(data.clientId())
        .alertType(data.alertType())
        .expectedTotal(data.expectedTotal())
        .actualTotal(data.actualTotal())
        .delta(data.delta())
        .shortfallAmount(data.shortfallAmount())
        .clientFrozen(data.clientFrozen())
        .platformFrozen(data.platformFrozen())
        .unrecoveredAmount(data.unrecoveredAmount())
        .perRecipientBreakdown(data.perRecipientBreakdown())
        .financialAction(data.financialAction())
        .status(EntityStatus.ACTIVE)
        .build();
    alertRepository.save(alert);

    // Publish audit event (consistent with PlatformFreezeService pattern)
    AuditEventType auditType = data.alertType() == DeviationAlertType.PLATFORM_FREEZE
        ? AuditEventType.PLATFORM_FREEZE_SHORTFALL
        : AuditEventType.SEGMENT_DEVIATION;
    eventPublisher.publishEvent(new DomainAuditEvent(
        auditType,
        data.clientId(),
        "system",
        "Segment deviation: sendRequestId=" + data.sendRequestRef()
            + ", delta=" + data.delta()
            + ", action=" + data.financialAction()
    ));

    log.info("Created {} deviation alert for sendRequestId={}, delta={}, action={}",
        data.alertType(), data.sendRequestRef(), data.delta(), data.financialAction());
}
```

Create FinalBookingService.java in gateway/billing/service/.

Annotations: @Service @Transactional @Slf4j @RequiredArgsConstructor

Javadoc on class: "Orchestrates post-send billing finalization using Nexah's actual segment totals. Implements the 6 BOOK scenarios (BOOK-01 through BOOK-06) and creates SEGMENT or PLATFORM_FREEZE deviation alerts for any non-zero deviation. Lock order: (1) reservation row [via CreditReservationService.debit()], (2) client credit balance [via ClientCreditBalanceRepository.findByClientIdForUpdate()], (3) platform credit balance [via PlatformCreditBalanceRepository.findForUpdate()]. Never invert this order."

Injected dependencies:
- CreditReservationService creditReservationService
- CreditService creditService
- PlatformCreditService platformCreditService
- ClientFreezeService clientFreezeService
- PlatformFreezeService platformFreezeService
- SegmentDeviationService segmentDeviationService
- ClientCreditBalanceRepository clientCreditBalanceRepository
- PlatformCreditBalanceRepository platformCreditBalanceRepository
- SendRequestRepository sendRequestRepository
- SendRequestRecipientRepository recipientRepository

Note: ClientFreezeService is in gateway.account.service — cross-module service injection is permitted per ARCHITECTURE.md and existing precedent (same injection pattern is already used in CreditReservationService).

Public method signature:
```java
public void book(Long clientId, String sendRequestId, long actualSegmentsTotal, Long reservationId)
```

Implementation steps:

1. Load SendRequest: `sendRequestRepository.findByClientIdAndSendRequestId(clientId, sendRequestId).orElseThrow(...)`. If no reservationId, log warn and return (same guard as current listener).

2. If actualSegmentsTotal == 0: call `creditReservationService.release(clientId, reservationId)` and return. (All failed before dispatch — no deviation alert needed.)

3. Compute:
   - `long expectedTotal = sendRequest.getRawExpectedCredits()` (unbuffered, set by Phase 21)
   - `long reservedTotal = sendRequest.getReservedCredits()` (buffered = expectedTotal + recipientCount)
   - `long delta = actualSegmentsTotal - expectedTotal`

4. Determine scenario and execute:

   **BOOK-01/02/03 (actualSegmentsTotal <= reservedTotal):**
   - Call: `creditReservationService.debit(clientId, reservationId, actualSegmentsTotal)`
   - If delta == 0 (BOOK-02): no alert. Log and return.
   - If delta != 0 (BOOK-01 or BOOK-03): build alert with financialAction="REFUNDED", call `segmentDeviationService.createAlert(...)`.

   **BOOK-04/05/06 (actualSegmentsTotal > reservedTotal):**
   - `long extra = actualSegmentsTotal - reservedTotal`
   - Acquire client balance lock (CRITICAL — must use FOR UPDATE to prevent TOCTOU):
     ```java
     ClientCreditBalance clientLock = clientCreditBalanceRepository.findByClientIdForUpdate(clientId)
         .orElseThrow(...);
     long clientAvailable = clientLock.getBalance();
     ```
   - Call: `creditReservationService.debit(clientId, reservationId, reservedTotal)` (consume full reservation — never pass actualSegmentsTotal here; debit() throws if amount > reserved)

   If `clientAvailable >= extra` → **BOOK-04:**
   - `creditService.applyLedgerEntry(clientId, LedgerEntryType.SMS_EXTRA_DEBIT, -extra, "extra-debit:" + sendRequestId)`
   - Build alert: financialAction="EXTRA_DEBITED", delta=delta, no shortfall.
   - `segmentDeviationService.createAlert(...)`.

   If `clientAvailable < extra` → **BOOK-05/06:**
   - `long shortfall = extra - clientAvailable`
   - Drain client to zero: `creditService.applyLedgerEntry(clientId, LedgerEntryType.SMS_EXTRA_DEBIT, -clientAvailable, "extra-debit-drain:" + sendRequestId)` (only if clientAvailable > 0)
   - Acquire platform balance lock (lock 3 — after client lock 2):
     ```java
     PlatformCreditBalance platformLock = platformCreditBalanceRepository.findForUpdate()
         .orElseThrow(...);
     long platformAvailable = platformLock.getBalance();
     ```
   - Freeze client: `clientFreezeService.freeze(clientId, "Shortfall absorption: " + shortfall + " credits unreserved from sendRequestId=" + sendRequestId)`

   If `platformAvailable >= shortfall` → **BOOK-05:**
   - `platformCreditService.applyLedgerEntry(PlatformLedgerEntryType.SHORTFALL_ABSORPTION, -shortfall, "shortfall:" + sendRequestId)`
   - Build alert: alertType=SEGMENT, financialAction="SHORTFALL_ABSORBED", shortfallAmount=shortfall, clientFrozen=true.
   - `segmentDeviationService.createAlert(...)`.

   If `platformAvailable < shortfall` → **BOOK-06:**
   - `long unrecovered = shortfall - platformAvailable`
   - `platformCreditService.applyLedgerEntry(PlatformLedgerEntryType.SHORTFALL_ABSORPTION, -platformAvailable, "shortfall-partial:" + sendRequestId)` (absorb what's available, not the full shortfall — never pass -shortfall here; applyLedgerEntry throws InsufficientPlatformBalanceException if balance would go negative)
   - `platformFreezeService.freeze("Platform shortfall: unrecovered=" + unrecovered + " from sendRequestId=" + sendRequestId, unrecovered)`
   - Build SEGMENT alert: alertType=SEGMENT, financialAction="SHORTFALL_ABSORBED", shortfallAmount=shortfall, clientFrozen=true, platformFrozen=true, unrecoveredAmount=unrecovered.
   - `segmentDeviationService.createAlert(segmentAlertData)` (SEGMENT alert)
   - Build and create a second PLATFORM_FREEZE alert: alertType=PLATFORM_FREEZE, financialAction="SHORTFALL_ABSORBED", shortfallAmount=unrecovered, clientFrozen=true, platformFrozen=true, unrecoveredAmount=unrecovered.
   - `segmentDeviationService.createAlert(platformFreezeAlertData)`

5. For all alerts: load per-recipient breakdown from DB using `recipientRepository.findBySendRequestIdFk(sendRequest.getId())` and map each row to `new SegmentDeviationAlert.RecipientDeviationEntry(r.getRecipient(), r.getExpectedSegments(), r.getSegmentsConsumed() != null ? r.getSegmentsConsumed() : 0, (r.getSegmentsConsumed() != null ? r.getSegmentsConsumed() : 0) - r.getExpectedSegments())`.

Update SmsFinalisedBillingListener.java — replace the entire body of onSmsFinalized() with a delegation. The new listener:
- Injects FinalBookingService (inject it; remove the direct CreditReservationService injection)

- Remove the null reservationId guard (FinalBookingService owns that logic internally)
- Keep @EventListener and @Transactional on onSmsFinalized()
