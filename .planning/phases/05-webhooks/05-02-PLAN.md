**SmsFinalisedListener.java** — new file in package `com.softropic.sendam.client.infrastructure.listener`. Create the `infrastructure/listener/` directory.

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class SmsFinalisedListener {

    private final WebhookEndpointRepository webhookEndpointRepository;
    private final WebhookDeliveryRepository webhookDeliveryRepository;
    private final ObjectMapper objectMapper;   // Spring Boot auto-configures a Jackson ObjectMapper bean

    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void onSmsFinalized(SmsFinalisedEvent event) {
        List<WebhookEndpoint> endpoints = webhookEndpointRepository
                .findByClientIdAndStatus(event.clientId(), WebhookStatus.ACTIVE);

        if (endpoints.isEmpty()) {
            return;  // client has no active webhook — nothing to do
        }

        for (WebhookEndpoint endpoint : endpoints) {
            for (SmsFinalisedEvent.RecipientSummary summary : event.recipients()) {
                String payload = buildPayload(event.sendRequestId(), summary);
                String deliveryStatus = summary.finalStatus() == SendRequestStatus.FINALIZED
                        ? "DELIVERED"
                        : "FAILED";

                WebhookDelivery delivery = new WebhookDelivery();
                delivery.setWebhookEndpointId(endpoint.getId());
                delivery.setClientId(event.clientId());
                delivery.setSendRequestId(event.sendRequestId());
                delivery.setRecipient(summary.recipient());
                delivery.setGatewayMessageId(summary.gatewayMessageId());
                delivery.setDeliveryStatus(deliveryStatus);
                delivery.setPayload(payload);
                delivery.setStatus(WebhookDeliveryStatus.PENDING);
                delivery.setAttemptCount(0);
                delivery.setNextAttemptAt(Instant.now());

                webhookDeliveryRepository.save(delivery);
            }
        }
    }

    private String buildPayload(String sendRequestId, SmsFinalisedEvent.RecipientSummary summary) {
        // Build JSON string matching v8 contract section 12.2 exactly:
        // {"event":"sms.finalized","sendRequestId":"...","recipient":"...","gateway_message_id":"...","status":"DELIVERED"}
        String deliveryStatus = summary.finalStatus() == SendRequestStatus.FINALIZED
                ? "DELIVERED"
                : "FAILED";
        try {
            Map<String, String> map = new LinkedHashMap<>();
            map.put("event", "sms.finalized");
            map.put("sendRequestId", sendRequestId);
            map.put("recipient", summary.recipient());
            map.put("gateway_message_id", summary.gatewayMessageId() != null ? summary.gatewayMessageId() : "");
            map.put("status", deliveryStatus);
            return objectMapper.writeValueAsString(map);
        } catch (JsonProcessingException e) {
            log.error("Failed to serialize webhook payload for sendRequestId={} recipient={}",
                    sendRequestId, summary.recipient(), e);
            // Fallback: construct manually to never drop delivery rows
            return "{\"event\":\"sms.finalized\",\"sendRequestId\":\"" + sendRequestId
                    + "\",\"recipient\":\"" + summary.recipient() + "\",\"status\":\"" + deliveryStatus + "\"}";
        }
    }
}
```

Key pitfall to avoid: `@TransactionalEventListener(phase = AFTER_COMMIT)` runs after the outer TX commits — there is NO ambient transaction at that point. The `@Transactional(propagation = REQUIRES_NEW)` opens a fresh transaction specifically for writing delivery rows. Without it, `webhookDeliveryRepository.save()` throws `TransactionRequiredException`. This is documented as Pitfall 1 in the research.

**`dispatchPendingDeliveries()` — the poller:**
```java
@Scheduled(fixedDelay = 30_000)
@Transactional
public void dispatchPendingDeliveries() {
    Instant now = Instant.now();
    List<WebhookDelivery> due = webhookDeliveryRepository
            .findByStatusAndNextAttemptAtBefore(WebhookDeliveryStatus.PENDING, now);

    for (WebhookDelivery delivery : due) {
        try {
            dispatchOne(delivery);
        } catch (Exception e) {
            log.error("Unexpected error dispatching webhook delivery id={}", delivery.getId(), e);
            // advance to next backoff without crashing the entire poller
            applyFailure(delivery, null);
        }
    }
}
```

Use `fixedDelay` (not fixedRate) — consistent with SmsSchedulerService. Prevents overlapping runs.

**`dispatchOne(WebhookDelivery delivery)` — single dispatch:**
```java
private void dispatchOne(WebhookDelivery delivery) {
    // Load the endpoint URL
    WebhookEndpoint endpoint = webhookEndpointRepository.findById(delivery.getWebhookEndpointId())
            .orElse(null);
    if (endpoint == null || endpoint.getStatus() != WebhookStatus.ACTIVE) {
        // Endpoint deleted or deactivated — mark exhausted, do not retry
        delivery.setStatus(WebhookDeliveryStatus.EXHAUSTED);
        webhookDeliveryRepository.save(delivery);
        return;
    }

    delivery.setAttemptCount(delivery.getAttemptCount() + 1);
    delivery.setLastAttemptAt(Instant.now());

    try {
        ResponseEntity<String> response = postWebhook(endpoint.getUrl(), delivery.getPayload());
        if (response.getStatusCode().is2xxSuccessful()) {
            delivery.setStatus(WebhookDeliveryStatus.DELIVERED);
            delivery.setHttpStatus(response.getStatusCode().value());
            webhookDeliveryRepository.save(delivery);
            log.info("Webhook delivery id={} DELIVERED to {} (attempt {})",
                    delivery.getId(), endpoint.getUrl(), delivery.getAttemptCount());
        } else {
            delivery.setHttpStatus(response.getStatusCode().value());
            applyFailure(delivery, response.getStatusCode().value());
        }
    } catch (RestClientException e) {
        log.warn("Webhook delivery id={} HTTP error on attempt {}: {}",
                delivery.getId(), delivery.getAttemptCount(), e.getMessage());
        applyFailure(delivery, null);
    }
}
```

**`applyFailure(WebhookDelivery delivery, Integer httpStatus)` — backoff formula:**
```java
private void applyFailure(WebhookDelivery delivery, Integer httpStatus) {
    if (httpStatus != null) {
        delivery.setHttpStatus(httpStatus);
    }
    int nextAttempt = delivery.getAttemptCount() + 1;
    Instant next = nextAttemptAt(nextAttempt);
    if (next == null) {
        delivery.setStatus(WebhookDeliveryStatus.EXHAUSTED);
        log.warn("Webhook delivery id={} EXHAUSTED after {} attempts", delivery.getId(), delivery.getAttemptCount());
    } else {
        delivery.setNextAttemptAt(next);
        // status stays PENDING — poller picks it up again after backoff window
    }
    webhookDeliveryRepository.save(delivery);
}

private Instant nextAttemptAt(int nextAttemptNumber) {
    return switch (nextAttemptNumber) {
        case 2 -> Instant.now().plusSeconds(60);       // +1 min
        case 3 -> Instant.now().plusSeconds(300);      // +5 min
        case 4 -> Instant.now().plusSeconds(1_800);    // +30 min
        case 5 -> Instant.now().plusSeconds(7_200);    // +2 hours
        default -> null;                               // EXHAUSTED
    };
}
```

Max 5 attempts (nextAttempt==6 returns null -> EXHAUSTED). The attempt_count field tracks completed attempts; nextAttemptNumber = attemptCount + 1.

**`postWebhook()` — inner HTTP call with @Retryable:**
```java
@Retryable(
    retryFor = { RestClientException.class },
    maxAttempts = 2,
    backoff = @Backoff(delay = 500, multiplier = 2.0)
)
public ResponseEntity<String> postWebhook(String url, String payload) {
    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.APPLICATION_JSON);
    HttpEntity<String> entity = new HttpEntity<>(payload, headers);
    return webhookRestTemplate.postForEntity(url, entity, String.class);
}

@Recover
public ResponseEntity<String> postWebhookFallback(RestClientException e, String url, String payload) {
    throw new RestClientException("Webhook HTTP call failed after inner retries: " + e.getMessage()) {};
}
```

`@Retryable` requires `@EnableRetry` on a `@Configuration` class in the same application context — already added to `WebhookConfig` in Plan 05-01.

Note: `postWebhook()` must be a public method on a Spring-managed bean (not a private helper) for `@Retryable` AOP proxy to intercept it. `WebhookService` is already a `@Service` singleton, so AOP proxying applies.

Also: `dispatchPendingDeliveries` must NOT be called from within the same class (self-invocation bypasses AOP proxy for `@Scheduled`). It is called by the Spring scheduler infrastructure, not by `dispatchOne` or any internal method — this is already correct by design.
