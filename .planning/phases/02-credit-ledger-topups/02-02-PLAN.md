Create V4__topup_request.sql:

```sql
CREATE TABLE main.topup_request (
    id              BIGINT PRIMARY KEY,
    client_id       BIGINT NOT NULL REFERENCES main.client_account(id),
    amount          BIGINT NOT NULL CHECK (amount > 0),
    transaction_id  VARCHAR(200) NOT NULL,
    payment_type    VARCHAR(50) NOT NULL,
    account_number  VARCHAR(50),
    topup_status    VARCHAR(30) NOT NULL DEFAULT 'PENDING_APPROVAL',
    approved_at     TIMESTAMP,
    rejected_at     TIMESTAMP,
    status          VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',
    created_by           VARCHAR(50),
    created_date         TIMESTAMP,
    last_modified_by     VARCHAR(50),
    last_modified_date   TIMESTAMP,
    request_id           VARCHAR(100),
    session_id           TEXT,
    CONSTRAINT uq_topup_client_txn UNIQUE (client_id, transaction_id)
);
CREATE INDEX idx_topup_client_status ON main.topup_request(client_id, topup_status);
```

  - Catch DataIntegrityViolationException: throw new DuplicateTransactionIdException("Duplicate transaction_id for this client") — create this in com.softropic.sendam.client.contract.exception, extends ApplicationException; add @ExceptionHandler to ApiAdvice returning 409 with error_code "DUPLICATE_TRANSACTION_ID"
  - Write informational TOPUP_PENDING ledger entry: creditService.applyLedgerEntry(clientId, LedgerEntryType.TOPUP_PENDING, 0L, formatTopupId(saved.getId()))
    NOTE: amount=0 — this entry does NOT change the balance, it is a pure audit record
  - return new CreateTopupResponse(formatTopupId(saved.getId()), TopupStatus.PENDING_APPROVAL, saved.getCreatedDate())
- Method: @Transactional(readOnly = true) TopupStatusResponse getTopupStatus(Long clientId, String topupId)
  - parse topupId to Long via parseTopupId
  - topupRepository.findByClientIdAndId(clientId, id).orElseThrow(() -> new ResourceNotFoundException("topup_id not found"))
  - return new TopupStatusResponse(topupId, entity.getAmount(), entity.getTopupStatus(), entity.getApprovedAt())
- Method: TopupStatusResponse approve(String topupId)
  - parse topupId
  - Acquire lock: topupRepository.findByIdForUpdate(id).orElseThrow(() -> new ResourceNotFoundException("topup_id not found"))
  - if entity.getTopupStatus() != PENDING_APPROVAL: throw new TopupAlreadyProcessedException("Top-up is already " + entity.getTopupStatus()) — create in contract.exception, 409, error_code "TOPUP_ALREADY_PROCESSED"
  - creditService.applyLedgerEntry(entity.getClientId(), LedgerEntryType.TOPUP_APPROVED, entity.getAmount(), topupId)
    NOTE: amount is positive here — this CREDITS the balance
  - entity.setTopupStatus(TopupStatus.APPROVED); entity.setApprovedAt(Instant.now()); topupRepository.save(entity);
  - return new TopupStatusResponse(topupId, entity.getAmount(), TopupStatus.APPROVED, entity.getApprovedAt())

  - parse topupId
  - Acquire lock: topupRepository.findByIdForUpdate(id).orElseThrow(() -> new ResourceNotFoundException("topup_id not found"))

  - return new TopupStatusResponse(topupId, entity.getAmount(), TopupStatus.REJECTED, null)
