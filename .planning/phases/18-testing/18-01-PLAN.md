<task type="auto">
  <name>Task 2: Write vitest.config.mjs with src alias and jsdom environment</name>
  <files>src/frontend/vitest.config.mjs</files>
  <action>
Create (or overwrite if extension generated one) `src/frontend/vitest.config.mjs` with this exact content:

```javascript
import { defineConfig } from 'vitest/config'
import vue from '@vitejs/plugin-vue'
import { quasar, transformAssetUrls } from '@quasar/vite-plugin'
import { fileURLToPath } from 'node:url'

export default defineConfig({
  test: {
    environment: 'jsdom',
    setupFiles: ['test/vitest/setup-file.js'],
    globals: true,
  },
  plugins: [
    vue({
      template: { transformAssetUrls },
    }),
    quasar({ sassVariables: false }),
  ],
  resolve: {
    alias: {
      src: fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
})
```

Key decisions:
- `sassVariables: false` — no sass processing in test environment (avoids sass dependency issues)
- `globals: true` — allows `describe`/`it`/`expect`/`vi` without explicit imports in test files
- `environment: 'jsdom'` — DOM environment for Vue component rendering
- `src` alias — matches Quasar's default `src/` alias so `import 'src/...'` resolves in tests
- Do NOT add an alias for `#q-app/wrappers` — that symbol is blocked entirely by mocking `src/boot/axios` in the setup file (simpler and more explicit)
  </action>
  <verify>
```bash
cd src/frontend && node --input-type=module <<'EOF'
import { readFileSync } from 'fs'
const content = readFileSync('vitest.config.mjs', 'utf-8')
if (!content.includes("environment: 'jsdom'")) throw new Error('missing jsdom')
if (!content.includes("setup-file.js")) throw new Error('missing setupFiles')
if (!content.includes("src: fileURLToPath")) throw new Error('missing src alias')
console.log('vitest.config.mjs OK')
EOF
```
  </verify>
  <done>vitest.config.mjs exists with jsdom environment, setup-file.js in setupFiles, and src alias pointing to ./src.</done>

<task type="auto">
  <name>Task 3: Create setup-file.js with global axios boot mock</name>
  <files>src/frontend/test/vitest/setup-file.js</files>
  <action>
Create `src/frontend/test/vitest/setup-file.js`. If the directory `test/vitest/` does not exist, create it first.

Content:

```javascript
import { vi } from 'vitest'

/**
 * Global mock for src/boot/axios.
 *
 * src/boot/axios imports '#q-app/wrappers' which is a Quasar CLI virtual module
 * that does not exist in the Vitest/jsdom environment. Mocking the entire boot
 * file here prevents the import chain from crashing before any test runs.
 *
 * Each test file mocks src/api/admin directly via vi.mock('src/api/admin', ...)
 * so the `api` stub here is never actually called — it just satisfies the import.
 */
vi.mock('src/boot/axios', () => ({
  default: vi.fn(),
  api: {
    get:    vi.fn(),
    post:   vi.fn(),
    put:    vi.fn(),
    delete: vi.fn(),
  },
  onLoadingChange: vi.fn(() => () => {}),
}))
```

If the extension already created a `setup-file.ts`, rename it:
```bash
mv src/frontend/test/vitest/setup-file.ts src/frontend/test/vitest/setup-file.js
```
Then replace its contents with the above.
  </action>
