**Extend `DeliveryAnalyticsService` — add two methods after `getSegmentTotals`:**

```java
public ClientDeliveryStatsResponse getClientDeliveryStats(Long clientId, Instant from, Instant to) {
    DeliveryStatRow summary = repository.findDeliveryStats(clientId, from, to);
    long totalSent  = summary.getTotalSent();
    long delivered  = summary.getDelivered();
    long failed     = summary.getFailed();
    double rate     = totalSent == 0 ? 0.0 : (double) delivered / totalSent * 100.0;
    return new ClientDeliveryStatsResponse(totalSent, delivered, failed, rate, summary.getTotalSegments());
}

public ClientSegmentTotalsResponse getClientSegmentTotals(Long clientId, Instant from, Instant to) {
    DeliveryStatRow summary = repository.findDeliveryStats(clientId, from, to);
    return new ClientSegmentTotalsResponse(summary.getTotalSegments(), from, to);
}
```

clientId is mandatory here (non-null Long from the security context). Do NOT call
`repository.findDailyBreakdown` — daily breakdown is out of scope for client endpoints.

**Add constant to `AppEndpoints.java`:**

After the existing `WEBHOOKS_API` constant declaration, add:

```java
public static final String CLIENT_ANALYTICS = "/v1/analytics/**";
```

Do NOT add an entry to `SECURED_MAPPINGS`. The `/v1/**` catch-all already covers
`/v1/analytics/**` in the JWT chain, and client requests never reach the JWT chain anyway.
The constant exists purely for reference from `ClientSecurityConfiguration`.

**Update `ClientSecurityConfiguration.java`:**

In `clientApiSecurityFilterChain`, change the `securityMatcher(...)` call from:

```java
.securityMatcher(AppEndpoints.SMS_API, AppEndpoints.CREDITS_API,
                 AppEndpoints.CLIENT_API_KEYS, AppEndpoints.WEBHOOKS_API)
```

to:

```java
.securityMatcher(AppEndpoints.SMS_API, AppEndpoints.CREDITS_API,
                 AppEndpoints.CLIENT_API_KEYS, AppEndpoints.WEBHOOKS_API,
                 AppEndpoints.CLIENT_ANALYTICS)
```

This is the critical change. Without it, requests to `/v1/analytics/**` bypass the @Order(1)
API-key filter chain, fall through to the @Order(2) JWT chain, and fail with 401 even with a
valid API key.

**Create `ClientAnalyticsResource.java`** in package
`com.softropic.sendam.gateway.analytics.api`:

```java
@RestController
@RequestMapping("/v1/analytics")
@RequiredArgsConstructor
@Slf4j
public class ClientAnalyticsResource {

    private final DeliveryAnalyticsService analyticsService;
    private final SpendService spendService;

    @GetMapping("/delivery-stats")
    public ResponseEntity<ClientDeliveryStatsResponse> getDeliveryStats(
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) Instant from,
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) Instant to) {
        Long clientId = (Long) SecurityContextHolder.getContext().getAuthentication().getPrincipal();
        log.debug("Client delivery stats: clientId={}, from={}, to={}", clientId, from, to);
        return ResponseEntity.ok(analyticsService.getClientDeliveryStats(clientId, from, to));
    }

    @GetMapping("/segment-totals")
    public ResponseEntity<ClientSegmentTotalsResponse> getSegmentTotals(
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) Instant from,
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) Instant to) {
        Long clientId = (Long) SecurityContextHolder.getContext().getAuthentication().getPrincipal();
        log.debug("Client segment totals: clientId={}, from={}, to={}", clientId, from, to);
        return ResponseEntity.ok(analyticsService.getClientSegmentTotals(clientId, from, to));
    }

    @GetMapping("/credits-consumed")
    public ResponseEntity<ClientCreditConsumptionResponse> getCreditConsumption(
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) Instant from,
            @RequestParam(required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE_TIME) Instant to) {
        Long clientId = (Long) SecurityContextHolder.getContext().getAuthentication().getPrincipal();
        log.debug("Client credits consumed: clientId={}, from={}, to={}", clientId, from, to);
        return ResponseEntity.ok(spendService.getClientNetCreditsConsumed(clientId, from, to));
    }
}
```

No `@PreAuthorize` — security is enforced by the @Order(1) filter chain, not by role annotations.
No `clientId` request parameter — identity is extracted from the security context only.
clientId is never logged at INFO level — debug only (PII guard).
