    Create SmsSchedulerService as @Service @Slf4j @RequiredArgsConstructor:

    Dependencies to inject:
    - SendRequestRepository sendRequestRepository

    Method: dispatchScheduledMessages() → void
    - @Scheduled(fixedDelay = 30_000)  — runs every 30 seconds after the PREVIOUS run completes (fixedDelay, not fixedRate — prevents overlapping runs)
    - @Transactional
    - Body:
        Instant now = Instant.now()
        List&lt;SendRequest&gt; due = sendRequestRepository.findDueScheduledRequests(now)
        if (due.isEmpty()) return   // skip log noise on empty polls
        log.info("Dispatching {} due scheduled SMS request(s)", due.size())
        for (SendRequest request : due) {
            try {
                // Phase 3: mark SUBMITTED. Phase 4 replaces this with actual Nexah HTTP call.
                request.setSendStatus(SendRequestStatus.SUBMITTED)
                sendRequestRepository.save(request)
                log.info("Scheduled request {} marked SUBMITTED", request.getSendRequestId())
            } catch (Exception e) {
                log.error("Failed to dispatch scheduled request {}", request.getSendRequestId(), e)
                // Continue processing remaining requests — one failure must not block others
            }
        }

    Do NOT inject CreditReservationService into SmsSchedulerService. The scheduler only marks SUBMITTED for now. Credit debit (settle) is Phase 4's responsibility after Nexah confirms delivery.
  </action>
