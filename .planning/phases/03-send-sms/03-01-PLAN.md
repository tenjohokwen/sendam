    Create V5__send_request.sql in db/migration. The migration creates two tables:

    send_request (schema = main):
    - id BIGINT PRIMARY KEY
    - client_id BIGINT NOT NULL REFERENCES main.client_account(id)
    - send_request_id VARCHAR(200) NOT NULL  -- client-supplied idempotency key
    - sender VARCHAR(11) NOT NULL
    - message TEXT NOT NULL
    - send_status VARCHAR(30) NOT NULL DEFAULT 'ACCEPTED'
    - schedule_time TIMESTAMP  -- NULL = immediate, NOT NULL = scheduled
    - message_count INT NOT NULL
    - segment_count INT NOT NULL
    - reserved_credits BIGINT NOT NULL
    - reservation_id BIGINT NOT NULL  -- CreditLedgerEntry.id from reserve()
    - created_by VARCHAR(50), created_date TIMESTAMP, last_modified_by VARCHAR(50), last_modified_date TIMESTAMP
    - request_id VARCHAR(100), session_id TEXT
    - entity_status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE'
    - CONSTRAINT uq_send_request_client_ref UNIQUE (client_id, send_request_id)
    - INDEX idx_send_request_client_status ON (client_id, send_status)
    - PARTIAL INDEX idx_send_request_scheduled ON (schedule_time, send_status) WHERE schedule_time IS NOT NULL AND send_status = 'ACCEPTED'

    send_request_recipient (schema = main):
    - id BIGINT PRIMARY KEY
    - send_request_id_fk BIGINT NOT NULL REFERENCES main.send_request(id)
    - client_id BIGINT NOT NULL REFERENCES main.client_account(id)
    - recipient VARCHAR(20) NOT NULL
    - send_status VARCHAR(30) NOT NULL DEFAULT 'ACCEPTED'
    - gateway_message_id VARCHAR(100)    -- written by Phase 4
    - provider_message_id VARCHAR(200)   -- written by Phase 4
    - segments_consumed INT              -- written by Phase 4
    - created_by VARCHAR(50), created_date TIMESTAMP, last_modified_by VARCHAR(50), last_modified_date TIMESTAMP
    - request_id VARCHAR(100), session_id TEXT
    - status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE'  -- entity_status (inherited pattern)
    - INDEX idx_send_request_recipient_request ON (send_request_id_fk)
    - INDEX idx_send_request_recipient_client ON (client_id, send_status)

      A-Z, a-z, 0-9, space, and these special chars: @ £ $ ¥ è é ù ì ò Ç Ø ø Å å Δ _ Φ Γ Λ Ω Π Ψ Σ Θ Ξ Æ æ ß É
