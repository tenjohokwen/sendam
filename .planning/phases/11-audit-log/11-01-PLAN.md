```sql
CREATE TABLE main.audit_event (
    id           BIGINT      PRIMARY KEY,
    event_type   VARCHAR(50) NOT NULL,
    client_id    BIGINT      REFERENCES main.client_account(id),
    actor        VARCHAR(100) NOT NULL,
    detail       TEXT,
    occurred_at  TIMESTAMP   NOT NULL
);

CREATE INDEX idx_audit_event_client_occurred
    ON main.audit_event(client_id, occurred_at DESC)
    WHERE client_id IS NOT NULL;

CREATE INDEX idx_audit_event_occurred
    ON main.audit_event(occurred_at DESC);
```

Column notes:
- `id` — BIGINT, no GENERATED ALWAYS — populated by @Tsid from BaseEntity (all entities in this project use this pattern)
- `client_id` — nullable FK; purely admin events (e.g. CLIENT_CREATED) will have a client_id, but the column must accept NULL if future events have no client target
- `actor` — NOT NULL; stores admin username (from SecurityUtil.getCurrentUserLogin()) or "client:{clientId}" for client-initiated events
- `detail` — TEXT, nullable; human-readable context string

Do NOT add a `status` column. audit_event is append-only. No AbstractAuditingEntity columns needed.

```java
package com.softropic.sendam.gateway.audit.repo;

import com.softropic.sendam.common.persistence.BaseEntity;

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.Table;
import lombok.Getter;
import lombok.Setter;

import java.time.Instant;

@Entity
@Table(name = "audit_event", schema = "main")
@Getter
@Setter
public class AuditEventEntity extends BaseEntity {

    @Column(name = "event_type", nullable = false, length = 50)
    private String eventType;

    @Column(name = "client_id")
    private Long clientId;

    @Column(name = "actor", nullable = false, length = 100)
    private String actor;

    @Column(name = "detail", columnDefinition = "TEXT")
    private String detail;

    @Column(name = "occurred_at", nullable = false)
    private Instant occurredAt;
}
```

CRITICAL: Extends BaseEntity only — NOT AbstractAuditingEntity. AbstractAuditingEntity has a
@Column(name = "status") which is unneeded for an append-only audit table and would add an
unwanted column. BaseEntity provides the TSID `id` field only.

Do NOT add a `status` field. Do NOT add `createdDate` / `updatedDate` manually — they are not
in the migration schema and are not needed for audit rows.

**AuditEventRepository.java** — in gateway/audit/repo/:
```java
package com.softropic.sendam.gateway.audit.repo;

import com.softropic.sendam.gateway.audit.contract.AuditEventRow;

import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;
import org.springframework.data.repository.query.Param;
import org.springframework.stereotype.Repository;

import java.time.Instant;

@Repository
public interface AuditEventRepository extends JpaRepository<AuditEventEntity, Long> {

    @Query(value = """
        SELECT
            ae.id           AS id,
            ae.event_type   AS eventType,
            ae.client_id    AS clientId,
            ae.actor        AS actor,
            ae.detail       AS detail,
            ae.occurred_at  AS occurredAt
        FROM main.audit_event ae
        WHERE (:clientId IS NULL OR ae.client_id = :clientId)
          AND (:from IS NULL     OR ae.occurred_at >= :from)
          AND (:to   IS NULL     OR ae.occurred_at <= :to)
        ORDER BY ae.occurred_at DESC
        """,
        countQuery = """
        SELECT COUNT(*)
        FROM main.audit_event ae
        WHERE (:clientId IS NULL OR ae.client_id = :clientId)
          AND (:from IS NULL     OR ae.occurred_at >= :from)
          AND (:to   IS NULL     OR ae.occurred_at <= :to)
        """,
        nativeQuery = true)
    Page<AuditEventRow> findEvents(
        @Param("clientId") Long clientId,
        @Param("from") Instant from,
        @Param("to") Instant to,
        Pageable pageable
    );
}
```

Use JpaRepository (not Repository<Object, Long>) — this repository is entity-bound and needs
Spring Data's save/findById/etc for the write side. The native query with Pageable requires an
explicit countQuery — do NOT omit it.
