<objective>
Unblock APIKEY-01, APIKEY-02, APIKEY-03 by adding /v1/api/** to the @Order(1) API key security filter chain
and removing the dead TOPUPS_API constant that guards a path no controller owns.

Purpose: The three API key self-service endpoints (ClientApiKeyResource at /v1/api/keys) are fully
implemented but unreachable. ClientSecurityConfiguration's securityMatcher does not include /v1/api/**,
so those requests fall through to the @Order(2) JWT chain which returns 403 for API-key-authenticated
clients. Adding CLIENT_API_KEYS to the matcher and removing the defunct TOPUPS_API closes CRITICAL-1 and
CRITICAL-2 from the v1.0 milestone audit.

Output: Two modified source files and one new integration test confirming routing is correct.
</objective>
